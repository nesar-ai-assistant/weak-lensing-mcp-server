Weak Lensing Surveys MCP Server: public cosmic-shear / 3x2pt products of DES Y3 (Y6 not yet public), KiDS-1000, KiDS-Legacy and HSC Y3. Start with list_wl_datasets / describe_wl_dataset; list_wl_skills for recipes (wl-tour first). Typical flow: fetch_wl_datavector(dataset, statistic) -> CSV (bin1, bin2, angbin, x, value, error) + covariance .npy -> plot_shear_correlation / plot_covariance / compute_signal_to_noise; plot_redshift_distributions for n(z); fetch_wl_chain -> analyze_wl_chain (heavy) -> plot_s8_om_contours; compare_s8_constraints for S8 tension vs Planck 2018 (0.832 +/- 0.013). Conventions: theta in arcmin, xi dimensionless, bins 1-based (gammat: bin1 = lens, bin2 = source), S8 = sigma8 sqrt(Omega_m/0.3); published data vectors are uncut (no scale cuts applied by this server). Data download on first use into ~/.cache/cosmo-mcp/weak-lensing-mcp-server (override $COSMO_MCP_DATA); KiDS releases are 50-130 MB tarballs. HSC Y3 chains require HSC-SSP credentials: tools raise an error with manual-download instructions. Tools that write files take an output_dir and return ArtifactResult; pass file paths between tools, never raw arrays. Heavy tools can run on ALCF/NERSC via the hep-genesis IRI dispatch engine (set_dispatch / export_dispatch_pack); this server holds no facility credentials.
